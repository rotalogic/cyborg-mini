# CYBORG State — (nama pengguna)

Template state SATU FILE untuk CYBORG Mini. Salin file ini menjadi
`cyborg-state.md`, lalu isi. Aturan keras: maks. 3 goal berstatus active;
setiap mission aktif punya tepat SATU next action (kata kerja + objek,
≤ 15 kata); perubahan status ditambah sebagai catatan bertanggal,
jangan menulis ulang sejarah diam-diam.
